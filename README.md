# 🧠 Introvert vs Extrovert Personality Prediction Using Machine Learning

## 📌 Project Overview

This project predicts whether a person is an **Introvert** or an **Extrovert** using Machine Learning techniques. The model analyzes personality-related features and provides accurate predictions through an interactive Streamlit web application.

## 🎯 Objective

To build a machine learning model that can classify individuals as:

* Introvert
* Extrovert

## ⚙️ Technologies Used

* Python 🐍
* Pandas
* NumPy
* Scikit-learn
* Joblib
* Streamlit
* VS Code

## 📊 Dataset Information

The dataset contains personality-related features such as:

* Time Spent Alone
* Social Event Attendance
* Going Outside Frequency
* Friends Circle Size
* Social Media Post Frequency
* Stage Fear
* Drained After Socializing
* Personality Type (Target Variable)

## 🤖 Machine Learning Model

**Algorithm:** Random Forest Classifier

### Steps:

* Data Cleaning
* Handling Missing Values
* Encoding Categorical Data
* Feature Selection
* Model Training
* Model Evaluation

## 📈 Model Evaluation

* Accuracy Score
* Confusion Matrix
* Classification Report


## 🎯 Prediction Output

The model predicts whether a person is:

* Introvert
* Extrovert

based on the personality characteristics entered by the user.
